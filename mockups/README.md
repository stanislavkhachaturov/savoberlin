# SAVO — макеты дизайна (архив)

Три кликабельных варианта дизайна, сделанных до начала разработки, чтобы заказчик выбрал направление. Это не код сайта, а «живые макеты»: самостоятельные HTML-страницы без сборки, со всеми анимациями, адаптивом и немецким контентом.

**Заказчик выбрал вариант A**, из варианта B взят калькулятор стоимости. Боевой сайт лежит на уровень выше и от этой папки никак не зависит — макеты сохранены как история решений и как источник идей для будущих доработок (в B и C есть блоки, которых на сайте пока нет).

## Как посмотреть

```bash
cd alex/mockups
python3 -m http.server 4321
```

Открыть <http://localhost:4321/> — там витрина со всеми тремя вариантами. Файлы работают и двойным кликом, картинки лежат рядом. Шрифты грузятся с Google Fonts, поэтому для точного вида нужен интернет.

Чтобы отправить заказчику — заархивировать папку целиком (без `node_modules`) либо залить на любой статический хостинг.

## Что внутри

| Файл | Вариант | Идея |
| --- | --- | --- |
| `index.html` | витрина | Страница выбора на немецком, с превью и описанием вариантов |
| `variante-a.html` | Midnight Gold | **Выбранный.** Тёмный, «дорогой», золото из логотипа, крупные фото |
| `variante-b.html` | Bento + Preisrechner | Светлый, bento-сетка вместо hero, калькулятор стоимости, липкий сплит-скролл |
| `variante-c.html` | Industrial | Технический: сталь, предупреждающие полосы, моноширинные подписи |

A и C построены по одному сценарию: hero, бегущая строка, три направления услуг, преимущества, ползунок «Vorher/Nachher», этапы, цифры, контакты, подвал. B специально сделан с другой структурой: bento-сетка, калькулятор, галерея «до/после» с перетаскиванием, горизонтальный таймлайн «Ein Tag im Einsatz», лента отзывов и FAQ.

## Чем отличается боевой сайт от варианта A

- добавлен калькулятор стоимости из варианта B, перерисованный в тёмно-золотую гамму;
- полностью вычитан немецкий текст (список правок — в основном README);
- заменена пара «Vorher/Nachher»: раньше это были явно разные помещения;
- добавлены блок FAQ, страницы Impressum, Datenschutz и своя страница 404.

## Ассеты

- `assets/logo-mark.svg` — логотип, перерисованный в вектор. Присланный PNG был 106×150 px и для сайта не годился; форма и цвет (`#DDC82A`) сохранены.
- `assets/img/*.webp` — фотографии с [Unsplash](https://unsplash.com/license) (свободны для коммерческого использования), в двух размерах.
- `shots/` — скриншоты вариантов, включая снимки собранного сайта на ранних итерациях.

## Инструменты

Здесь остались только те скрипты, что нужны для макетов и подбора фотографий. Проверки и скриншоты боевого сайта переехали в `../scripts` (`pnpm check`, `pnpm shots`).

```bash
pnpm install
node tools/search.mjs "moving truck" "berlin"            # поиск кадров на Unsplash
node tools/contact-sheet.mjs /tmp/sheet.jpg <id> <id> …  # превью-сетка кандидатов
node tools/fetch-images.mjs                              # скачать и пережать отобранные фото
node tools/shots.mjs variante-a --full                   # скриншоты макета (нужен сервер на :4321)
node tools/check.mjs                                     # санити-проверка макетов
```

Полезно, если понадобится добавить на сайт новые фотографии: `search.mjs` ищет кадры по запросу, `contact-sheet.mjs` собирает их в одну картинку для быстрого выбора глазами. Отобранные id прописываются в `../scripts/prepare-assets.mjs`.
